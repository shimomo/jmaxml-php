# jmaxml-php

気象庁防災情報XMLの **非公式** PHP ライブラリ群です。気象庁とは関係ありません。

An **unofficial** set of PHP libraries for JMA (Japan Meteorological Agency) disaster information XML. Not affiliated with JMA.

## パッケージ

| パッケージ | 内容 |
|---|---|
| [`jmaxml/core`](packages/core) | 電文を公式 XML スキーマから生成した型付きオブジェクトとして読む |
| [`jmaxml/codes`](packages/codes) | 地震関係のコード表（都道府県・細分区域・市町村・震度観測点・震央地名・津波予報区）を引く |
| [`jmaxml/feed`](packages/feed) | 公開 Atom フィードをポーリングし、新着の電文を絞り込んで返す（抜けの検知つき） |
| [`jmaxml/earthquake`](packages/earthquake) | 地震の電文を地震イベントにまとめ、登録した市町村が震度いくつ以上だったか、取り消されたかを判定する |

使い方は各パッケージの README を参照してください。

## 開発

```bash
composer install
composer test       # PHPUnit（実サーバーに接続するテストは除外。vendor/bin/phpunit --group live で実行）
composer analyse    # Psalm
composer lint       # Pint
composer generate   # resources/jmaxml から packages/core/src の型と packages/codes/src/Data のコード表を再生成
```

`packages/core/src` と `packages/codes/src/Data` のうち、先頭に `This file is generated by tools/codegen` とあるファイルは生成コードです。手で編集せず、`tools/codegen` を直して `composer generate` を実行してください。

## 出典

このリポジトリには、気象庁が公開している技術資料（XML スキーマ、辞書、サンプル電文）を `resources/jmaxml/` に同梱しています。

出典：気象庁ホームページ（https://xml.kishou.go.jp/）
