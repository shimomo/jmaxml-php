# jmaxml-php

気象庁防災情報XMLの **非公式** PHP ライブラリ群です。気象庁とは関係ありません。

An **unofficial** set of PHP libraries for JMA (Japan Meteorological Agency) disaster information XML. Not affiliated with JMA.

## パッケージ

| パッケージ | 内容 |
|---|---|
| [`jmaxml/core`](packages/core) | 電文を公式 XML スキーマから生成した型付きオブジェクトとして読む |

## 出典

このリポジトリには、気象庁が公開している技術資料（XML スキーマ、辞書、サンプル電文）を `resources/jmaxml/` に同梱しています。

出典：気象庁ホームページ（https://xml.kishou.go.jp/）
