# jmaxml-php

気象庁防災情報XMLの **非公式** PHP ライブラリ群です。気象庁とは関係ありません。

An **unofficial** set of PHP libraries for JMA (Japan Meteorological Agency) disaster information XML. Not affiliated with JMA.

## パッケージ

| パッケージ | 内容 | Packagist |
|---|---|---|
| [`jmaxml/core`](packages/core) | 電文を公式 XML スキーマから生成した型付きオブジェクトとして読む | [jmaxml/core](https://packagist.org/packages/jmaxml/core) |
| [`jmaxml/codes`](packages/codes) | 地震関係のコード表（都道府県・細分区域・市町村・震度観測点・震央地名・津波予報区）を引く | [jmaxml/codes](https://packagist.org/packages/jmaxml/codes) |
| [`jmaxml/feed`](packages/feed) | 公開 Atom フィードをポーリングし、新着の電文を絞り込んで返す（抜けの検知つき） | [jmaxml/feed](https://packagist.org/packages/jmaxml/feed) |
| [`jmaxml/earthquake`](packages/earthquake) | 地震の電文を地震イベントにまとめ、登録した市町村が震度いくつ以上だったか、取り消されたかを判定する | [jmaxml/earthquake](https://packagist.org/packages/jmaxml/earthquake) |

使い方は各パッケージの README を参照してください。

## 開発

```bash
composer install
composer test       # PHPUnit（実サーバーに接続するテストは除外。vendor/bin/phpunit --group live で実行）
composer analyse    # Psalm
composer lint       # Pint
composer generate   # resources/jmaxml から packages/core/src の型と packages/codes/src/Data のコード表を再生成
```

`packages/core/src` と `packages/codes/src/Data` のうち、先頭に `This file is generated by tools/codegen` とあるファイルは生成コードです。手で編集せず、`tools/codegen` を直して `composer generate` を実行してください。

## リリース

4 つのパッケージは、いつも同じ版番号でまとめて公開します。各パッケージは `shimomo/jmaxml-php-<package>` に分割され、Packagist にはその分割先を登録しています。

```bash
bin/release.sh 0.1.1
```

この 1 回の実行で、次のことを順に行います。

1. 事前確認（下の「止まる条件」）
2. `CHANGELOG.md` に版の見出しを入れる
3. `packages/*/composer.json` の相互依存（`^<version>`）と branch-alias を更新してコミットし、main を push する
4. 署名付きのタグを打って push する
5. 各パッケージを `git subtree split` で分割先に push し、タグと GitHub Release を作る

- **前提**：分割先の 4 リポジトリがあること、`gh` にログインしていること、`jq` と `composer` があること、タグに署名できる GPG（パスフレーズはキャッシュしておく）
- **版番号**：コード表の更新だけならパッチ版（`0.1.1`）、公開 API が変わるときはマイナー版（`0.2.0`）を上げます
- **CHANGELOG**：「Unreleased」に手書きの項目があれば、それをそのまま今回の版の項目にします。無ければ、直前のタグ以降のコミットの件名を使います
- **止まる条件**：版番号の形が違う、main にいない、未コミットの変更がある、同じタグが手元か origin にある、手元の main が origin とずれている、分割先のリポジトリに届かない。どれかに当たると、何も変えずに理由をすべて出して止まります

事前確認の後で失敗したときは、どこまで進んだかを確かめてから再開します。

- main とタグがまだ push されていなければ、`git status` でリリースが加えた変更を確かめ、それを戻してからやり直します
- main とタグが公開済み（`git ls-remote --tags origin <version>` で見える）なら、まだ公開されていないパッケージについてだけ、次を実行します

```bash
sh -c '. bin/lib/package-release.sh; package_release_publish 0.1.1 packages/feed'
```

## 出典

このリポジトリには、気象庁が公開している技術資料（XML スキーマ、辞書、サンプル電文、個別コード表）を `resources/jmaxml/` に同梱しています。`jmaxml/codes` のデータは、個別コード表を加工して作成したものです。

出典：[気象庁ホームページ](https://xml.kishou.go.jp/)
