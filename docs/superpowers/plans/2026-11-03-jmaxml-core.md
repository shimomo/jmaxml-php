# jmaxml/core 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 気象庁防災情報XMLの全電文を、公式 XSD から生成した型付き PHP オブジェクトとして読める `jmaxml/core` を、モノレポ `shimomo/jmaxml-php` の最初のパッケージとして作る。

**Architecture:** 公式 XSD 一式と辞書 xlsx を `tools/codegen`（PHP 製の開発用ジェネレーター）で読み、`final readonly class` を `packages/core/src` に生成してコミットする。生成コードは手書きの小さなランタイム（`Internal\Document`、`Internal\Node`、`Exception\ParseException`、`Geo`）だけに依存する。DOM（ext-dom の `DOMDocument`）で電文全体を読み、各クラスの `fromElement()` が自分の子要素を組み立てる。

**Tech Stack:** PHP ^8.4（ext-dom, ext-libxml。ジェネレーターだけ ext-zip）、PHPUnit ^13.2、Psalm ^6.0（errorLevel 1）、Laravel Pint ^1.27、ergebnis/composer-normalize ^2.52、GitHub Actions

**Spec:** `docs/superpowers/specs/2026-11-03-jmaxml-php-design.md`

**この計画の範囲:** 設計書の 4 パッケージのうち `jmaxml/core` と、モノレポの土台だけ。`codes`・`feed`・`seismology` は、この計画が終わって生成クラスの名前が確定してから、それぞれ別の計画として書く（後続の計画は core の生成クラス名に依存するため）。Packagist への公開とリリーススクリプトもこの計画の範囲外。

## Global Constraints

- PHP `^8.4`、ライセンス MIT、作者表記は `shimomo <yuichi@shimomo.net>`（boatrace-php と同じ）
- Packagist 名は `jmaxml/core`、ルートは `shimomo/jmaxml-php`。PHP 名前空間は `JmaXml\`
- core の実行時依存は `php`、`ext-dom`、`ext-libxml` だけ。ジェネレーターの依存は `require-dev` にも足さない（ext-zip のみ使う）
- すべての PHP ファイルは `declare(strict_types=1);`、クラスは `final`（値オブジェクトは `final readonly`）。boatrace-php と同じく、クラスの docblock に `@author shimomo` を付ける（生成コードは除く）
- `composer.json` の `description` は必ず「非公式（unofficial）」を含める。例：`"Unofficial parser for JMA (Japan Meteorological Agency) disaster information XML"`
- 生成ファイルの先頭（`declare` の直後）には、必ず次の 1 行を入れる：`// This file is generated by tools/codegen. Do not edit it by hand.`
- 生成コードは、`vendor/bin/pint --test` と `vendor/bin/psalm`（errorLevel 1）をそのまま通ること
- 名前空間の割り当て（後続パッケージと衝突させないため固定）：
  - core が使う：`JmaXml\`（`Report`、`Control`、`Body`、`Envelope`）、`JmaXml\InformationBasis\`、`JmaXml\ElementBasis\`、`JmaXml\Meteorology\`、`JmaXml\Seismology\`、`JmaXml\Volcanology\`、`JmaXml\Internal\`、`JmaXml\Exception\`、`JmaXml\Geo\`
  - 後続が使う：`JmaXml\Feed\`、`JmaXml\Codes\`、seismology パッケージは `JmaXml\Seismology\` が core の生成型で埋まっているため別名（その計画で決める）
  - ジェネレーター：`JmaXml\Codegen\`（`tools/codegen/src/`、autoload-dev のみ）
- 同梱する公式資料（`resources/jmaxml/`）：XSD 2024-10-31 版、辞書 2026-01-29 版、サンプル 2026-09-17 版。出典を `resources/jmaxml/README.md` に書く

## Review Focus

1. **実データの将来の変化**：未知の子要素や属性が増えた電文（マイナーバージョンアップ）でも、例外にならず読めること → Task 7 の `ignoresUnknownElementsAndAttributes`
2. **不正・悪意のある入力**：空文字列、XML でない文字列、DOCTYPE や実体参照を含む文書、ルートが `Report` でない文書では、PHP の warning を出さずに `ParseException` になること → Task 2 の `DocumentTest`
3. **繰り返し要素の中で必須要素が欠けたとき**：例外のパスに 1 始まりの添字が入り、どの要素か特定できること（例 `/Report/Head/Headline/Information[2]/Item`）→ Task 6 の `reportsIndexedPathForMissingElementInsideRepeatedElement`
4. **数値の端の値**：`NaN`、`INF`、`-INF`、`+5.9`、前後の空白、空文字列がそれぞれ決めたとおりに変換されること → Task 2 の `NodeTest`
5. **サンプルに無い `xsi:nil="true"` と座標の空値**：`Head/TargetDateTime` の nil は null、`condition="不明"` で空の座標は `points()` が空配列になること → Task 2 の `nillableDateTimeReturnsNullForXsiNil`、Task 3 の `emptyValueHasNoPoints`

{
    public function __construct(string $reason, public readonly string $path, ?\Throwable $previous = null);
    // getMessage() は "{$reason} at {$path}"
}

namespace JmaXml\Internal;
/** @internal */
final class Document
{
    public const string REPORT_NAMESPACE = 'http://xml.kishou.go.jp/jmaxml1/';
    public static function fromString(string $xml): \DOMElement;   // ルートの <Report> を返す
    public static function fromFile(string $path): \DOMElement;
}

/** @internal */
final class Node
{
    public const string XSI_NAMESPACE = 'http://www.w3.org/2001/XMLSchema-instance';
    // 子要素の取得（直下の子要素だけ見る。名前空間 URI と localName で照合）
    public static function one(\DOMElement $parent, string $namespace, string $localName, string $path): \DOMElement; // 無ければ ParseException(path: "$path/$localName")
    public static function optional(\DOMElement $parent, string $namespace, string $localName): ?\DOMElement;
    /** @return list<\DOMElement> */
    public static function many(\DOMElement $parent, string $namespace, string $localName): array;
    /** @return non-empty-list<\DOMElement> */
    public static function atLeastOne(\DOMElement $parent, string $namespace, string $localName, string $path): array; // 0 件なら ParseException(path: "$path/$localName")
    /** @template T @param callable(\DOMElement, string): T $map @return T|null */
    public static function mapOptional(?\DOMElement $element, string $path, callable $map): mixed;
    /** @template T @param list<\DOMElement> $elements @param callable(\DOMElement, string): T $map @return list<T> */
    public static function mapMany(array $elements, string $path, callable $map): array; // $map には "{$path}[1]", "{$path}[2]" … を渡す
    // 属性（名前空間なしの属性だけ）
    public static function attribute(\DOMElement $element, string $name): ?string;
    public static function requiredAttribute(\DOMElement $element, string $name, string $path): string; // 無ければ ParseException(path: "$path/@$name")
    // 値の変換
    public static function text(\DOMElement $element): string;                    // textContent をそのまま返す
    public static function toToken(string $raw): string;                           // 前後の XML 空白を除き、連続する空白を半角スペース 1 つに
    public static function toDateTime(string $raw, string $path): \DateTimeImmutable;
    public static function toNillableDateTime(\DOMElement $element, string $path): ?\DateTimeImmutable; // xsi:nil="true" なら null
    public static function toDuration(string $raw, string $path): \DateInterval;
    public static function toFloat(string $raw, string $path): ?float;             // NaN → null、空 → 例外
    public static function toNullableFloat(string $raw, string $path): ?float;     // 空 → null、NaN → null
    public static function toInt(string $raw, string $path): int;
    public static function toNullableInt(string $raw, string $path): ?int;         // 空 → null
    public static function toBool(string $raw, string $path): bool;                // true/false/1/0
    /** @return list<string> */
    public static function toList(string $raw): array;                             // XML 空白で分割、空なら []
}

- [ ] **Step 4: `ParseException`、`Document`、`Node` を実装する**

  - Document：`libxml_use_internal_errors(true)` で libxml のエラーを溜め、終わったら元の設定に戻す（`libxml_clear_errors()` も呼ぶ）。`DOMDocument::loadXML($xml, LIBXML_NONET)`。`LIBXML_NOBLANKS` は使わない（空白だけの値が消えるため）。失敗したら最初の libxml エラーの message を reason の後ろに付ける（`Malformed XML: ...`）。`$doc->doctype !== null` なら拒否する

**Files:**
- Create: `tools/codegen/src/Schema/{QName,ChildElement,Attribute,ComplexType,SchemaSet}.php`

**Interfaces:**
- Produces:

```php
namespace JmaXml\Codegen\Schema;
final readonly class QName { public function __construct(public string $namespace, public string $localName) {} } // XSD 組み込み型は namespace 'http://www.w3.org/2001/XMLSchema'
final readonly class ChildElement
{
    public function __construct(
        public string $name,          // 要素名（ref の場合は参照先の要素名）
        public string $namespace,     // 要素の名前空間（ローカル要素は schema の targetNamespace、ref は参照先）
        public QName $type,
        public int $minOccurs,
        public ?int $maxOccurs,       // null は unbounded
        public bool $nillable,
    ) {}
}
final readonly class Attribute { public function __construct(public string $name, public QName $type, public bool $required) {} }
final readonly class ComplexType
{
    public function __construct(
        public string $namespace,
        public string $prefix,            // 'jmx_seis' など（辞書のシート名と一致）
        public string $name,              // 'type.Earthquake' など
        public ?QName $simpleContentBase, // simpleContent の extension base。無ければ null
        /** @var list<ChildElement> */ public array $elements,
        /** @var list<Attribute> */ public array $attributes,
        public ?string $anyNamespace,     // xs:any の namespace 属性（'##other' や addition1 の URI）。無ければ null
    ) {}
}
final class SchemaSet
{
    public static function load(string $entryXsdPath): self;  // 入口の XSD から import/include を schemaLocation でたどって全ファイルを読む（実物は jmx.xsd から 8 ファイルすべてに届く）
    /** @return list<ComplexType> */ public function complexTypes(): array;  // (namespace, name) の順で安定ソート
    public function complexType(QName $name): ComplexType;     // 無ければ \LogicException
    public function isComplexType(QName $name): bool;
    public function simpleTypeBase(QName $name): QName;        // 名前付き simpleType を組み込み型まで解決（下記）
    public function prefixFor(string $namespace): string;      // その名前空間を targetNamespace とする XSD で、同じ URI に付いている xmlns の接頭辞
}
```

  XSD で使われている構文は、調査済みで次だけ：`complexType`（すべて名前付き、無名なし）、`sequence`（各 complexType に高々 1 つ、入れ子なし）、`simpleContent/extension`、`attribute`、`element`（`name`+`type` か `ref`）、`any`、`simpleType` の `restriction` / `list` / `union`。`complexContent`、`choice`、`group`、`default`、`fixed` は使われていない。これら以外の構文が現れたら `\LogicException` で止める（黙って無視しない）。

  `simpleTypeBase` の解決規則：`jmx_eb:nullablefloat` と `jmx_eb:nullableinteger` は名前でそのまま返す（ScalarKind が特別扱いする）。`restriction` は base をたどる。`list` は `QName(XS, 'list')` を返す。それ以外の `union`（`jmx:enum.UNION.type.control.Status`）は `QName(XS, 'string')` を返す。

| 対象 | 規則 | 例 |
|---|---|---|
| PHP 名前空間 | jmx → `JmaXml`、jmx_ib → `JmaXml\InformationBasis`、jmx_eb → `JmaXml\ElementBasis`、jmx_mete → `JmaXml\Meteorology`、jmx_seis → `JmaXml\Seismology`、jmx_volc → `JmaXml\Volcanology` | |

| プロパティ名（要素） | 要素名の先頭 1 文字だけを小文字にする | `EventID` → `eventID`、`TargetDTDubious` → `targetDTDubious`、`MaxInt` → `maxInt` |
| プロパティ名（属性） | 属性名のまま | `codeType`、`refID` |
| simpleContent の値 | プロパティ名 `value` | |

| XSD | PHP の型 | 変換 |
|---|---|---|
| xs:string、xs:anyURI、列挙・union（文字列） | `string` | `Node::text()`（加工しない） |
| xs:token | `string` | `Node::toToken()` |
| xs:dateTime | `\DateTimeImmutable`（nillable なら `?`） | `toDateTime` / `toNillableDateTime` |
| xs:duration | `\DateInterval` | `toDuration` |
| xs:float | `?float` | `toFloat`（NaN は null） |
| jmx_eb:nullablefloat | `?float` | `toNullableFloat` |
| xs:int、xs:unsignedByte | `int` | `toInt` |
| jmx_eb:nullableinteger | `?int` | `toNullableInt` |
| xs:boolean | `bool` | `toBool` |
| list.* | `list<string>` | `toList` |
| complexType | 生成クラス | `Xxx::fromElement($e, $p)` |

  出現回数：`1..1` は非 null（`Node::one`）、`0..1` は `?T`（`Node::optional` + `mapOptional`）、`0..*` は `list<T>`（`many` + `mapMany`）、`1..*` は `list<T>` で 1 件以上（`atLeastOne` + `mapMany`）。属性は `use="required"` なら非 null（`requiredAttribute`）、それ以外は `?T`。`xs:any` はプロパティを作らない。ただし `type.report` の `##other` だけは `body: Body` にする（下記）。
