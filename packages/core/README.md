# jmaxml/core

気象庁防災情報XMLの電文を、公式 XML スキーマから生成した型付きオブジェクトとして読む **非公式** PHP ライブラリです。気象庁とは関係ありません。

An **unofficial** PHP parser for JMA (Japan Meteorological Agency) disaster information XML. Not affiliated with JMA.

## 出典

型は気象庁が公開している XML スキーマと辞書から生成しています。

出典：気象庁ホームページ（https://xml.kishou.go.jp/）
